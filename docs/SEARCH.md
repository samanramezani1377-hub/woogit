# WooGit — Search

## نسخه اولیه

Global Search در نسخه اولیه جزو قابلیت‌های محوری نیست و نباید باعث سنگین شدن Core، UI یا مسیرهای اصلی شود.

### جستجوی scoped محصولات — الزامی در V1

با اینکه Global Search به آینده موکول شده، **جستجوی محصول در بخش مدیریت/اصلاح محصولات از همان نسخه اولیه ضروری است.**

کاربر باید بتواند در لیست محصولات، محصول موردنظر را سریع پیدا کند تا بتواند آن را اصلاح یا تکمیل کند. این Search باید scoped به Products باشد و برای سرعت کار طراحی شود.

حداقل باید برای پیدا کردن محصول بر اساس اطلاعات قابل جستجوی محصول آماده باشد و با افزایش تعداد محصولات، استفاده روزمره را کند نکند.

## آینده

معماری Core باید از ابتدا به شکلی باشد که در آینده بتوان یک Global Search سریع ایجاد کرد که بتواند بین Entityهای مختلف جستجو کند، از جمله:

- Orders
- Products
- Customers
- Notifications / Events در صورت نیاز
- چند Store در حالت Multi-Store

Search آینده باید Local-first و قابل استفاده با داده‌های ایندکس‌شده محلی باشد و در صورت نیاز نتایج سرور را نیز ترکیب کند.

## اصل Performance

آمادگی معماری برای Search آینده نباید به معنی ساخت ایندکس یا سرویس جستجوی سنگین در نسخه اول باشد. قابلیت باید در لایه آینده اضافه شود بدون اینکه مسیر سه محور اصلی محصول کند شود.
