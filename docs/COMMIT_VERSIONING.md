# WooGit — Per-Entity Commit Versioning

## تصمیم اصلی

شماره Commit باید به **خود موجودیت تغییرکرده** متصل باشد، نه فقط یک شمارنده‌ی کلی برای کل فروشگاه.

هر بار که یک موجودیت در سیستم واقعاً ثبت و به‌روز می‌شود، نسخه/Commit همان موجودیت باید تغییر کند.

مثال:

```text
Product #125
commit = 41

ویرایش قیمت Product #125
↓
commit = 42
```

ویرایش Product #126 نباید باعث شود نسخه‌ی Product #125 تغییر کند.

## موجودیت‌ها

این مدل باید حداقل برای موارد محوری زیر آماده باشد:

- Product
- Product Variation
- Order
- در آینده سایر Entityها و Eventهای قابل نسخه‌بندی

## Store-Level Version

در کنار نسخه‌ی هر Entity، Core می‌تواند یک Store Change Version سبک نیز نگه دارد تا اپ بتواند سریع تشخیص دهد که «آیا چیزی در فروشگاه تغییر کرده است یا نه» بدون اینکه مجبور به بررسی تک‌تک Entityها شود.

بنابراین دو مفهوم از هم جدا هستند:

1. **Entity Commit/Version:** مشخص می‌کند خود آن رکورد آخرین بار چه زمانی/با چه نسخه‌ای تغییر کرده است.
2. **Store Change Version:** یک نشانگر سریع برای تشخیص وجود هر تغییر جدید در کل فروشگاه.

این جداسازی برای Sync سریع و دقیق ضروری است.

## رفتار Sync

- تغییر از WooGit → ابتدا Local UI فوراً به‌روزرسانی می‌شود.
- پس از موفقیت ثبت روی فروشگاه → Entity Version به نسخه‌ی تأییدشده‌ی سرور می‌رسد.
- تغییر از WordPress/WooCommerce → افزونه‌ی همراه باید Entity Version همان رکورد و Store Change Version را به‌روزرسانی کند.
- اپ در Sync فقط Entityهای تغییرکرده را دریافت/ارسال می‌کند.
- یک تغییر در یک محصول نباید باعث دانلود مجدد کل محصولات شود.

## Performance Rule

Commit Versioning نباید باعث درخواست شبکه برای هر Entity شود. بررسی تغییرات باید تا حد ممکن با Store Change Version به یک درخواست سبک محدود شود و سپس فقط Entityهای تغییرکرده Sync شوند.

## Conflict

اگر نسخه‌ی محلی و نسخه‌ی سرور برای یک Entity متفاوت باشند، Sync Engine باید Conflict را تشخیص دهد و از overwrite کورکورانه جلوگیری کند. استراتژی حل Conflict در سند معماری مشخص خواهد شد.

## اصل آینده‌نگری

مدل Versioning باید از ابتدا generic باشد تا در آینده User Activity، Notification Event، تنظیمات و Entityهای جدید نیز در صورت نیاز قابل نسخه‌بندی باشند.
