# WooGit — New Order Notification Specification

## هدف

اعلان سفارش جدید مهم‌ترین و فوری‌ترین قابلیت WooGit است و باید اطلاعات کافی برای تصمیم‌گیری سریع را بدون باز کردن اپ در اختیار کاربر قرار دهد.

## محتوای اعلان

اعلان اصلی سفارش جدید باید تا حد امکان شامل موارد مهم زیر باشد:

- شماره سفارش
- مبلغ سفارش
- تعداد کالاها
- نام کالاها
- تاریخ سفارش
- ساعت سفارش

در آینده و در حالت Multi-Store، نام/شناسه فروشگاه نیز باید به‌وضوح قابل تشخیص باشد.

## Deep Link

با لمس اعلان، کاربر باید مستقیماً به جزئیات همان سفارش در WooGit هدایت شود.

## Deduplication

هر سفارش باید یک شناسه یکتای Event/Notification داشته باشد تا قطع و وصل شبکه، Retry، دریافت مجدد Webhook یا Sync باعث ایجاد اعلان تکراری برای همان رویداد نشود.

## فوریت

Notification باید سریع‌تر از جریان‌های عادی Sync عمل کند. هدف عملی اطلاع‌رسانی در مقیاس دقیقه است و نباید به polling مداوم وابسته باشد.

## معماری

Notification از Event Core تغذیه می‌شود و باید با Store ID، Order ID و Event ID قابل ردیابی باشد. این ساختار برای Multi-Store و Notification Center آینده ضروری است.

## UX

اعلان باید صریح و قابل فهم باشد و بدون اطلاعات غیرضروری، مهم‌ترین مشخصات سفارش را در همان اعلان ارائه کند.
