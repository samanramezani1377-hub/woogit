# References

Visual and design-direction references for AI agents and contributors working on WooGit's UI.
These are supporting material, not source of truth — the source of truth for UI/UX decisions is
[`../V1_DESIGN_SPEC.md`](../V1_DESIGN_SPEC.md) and [`../UI_UX_PRO_MAX.md`](../UI_UX_PRO_MAX.md).

| Reference | What it is |
|---|---|
| [`liquid-glass-theme/`](./liquid-glass-theme/) | Static HTML/CSS mockup of the WooGit home screen in the "Liquid Glass" visual language, with a full design-token breakdown for translating into Jetpack Compose. |

When adding a new reference, add its own folder with a `README.md` explaining what it is, how to
use it, and which tokens/rules an agent should extract from it — the same pattern as
`liquid-glass-theme/`.
