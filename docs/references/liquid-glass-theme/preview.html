Liquid Glass — Theme Reference

پس‌زمینه: چند بلاب رنگی محو (نعنایی، هلویی، بنفش، آبی) روی خاکستری خیلی روشن — نور از پشت شیشه.

کارت شیشه‌ای: rgba(255,255,255,.52) + backdrop-filter: blur(24px) saturate(160%) + یک لایه‌ی sheen مورب بالا برای حس نور روی شیشه.

عنصر امضادار: کارت «سفارش جدید» یک حلقه‌ی نبض‌دار نارنجی داره — چون اعلان سفارش تازه، اولین و فوری‌ترین ستون ووگیته. این ضربان بصری همون فوریتی رو منتقل می‌کنه که تو معماری real-time notification پروژه هست.

تایپوگرافی: Vazirmatn برای فارسی (تمام وزن‌ها)، JetBrains Mono برای اعداد/متادیتا (SKU، آمار، ساعت) تا خوانایی داده‌ها بالا بمونه.

این فایل یک HTML مستقل با CSS خالصه — قابل استفاده به‌عنوان مرجع رنگ/تایپ/فاصله‌گذاری برای پیاده‌سازی در Jetpack Compose.
